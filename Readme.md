# 🌐 Web Scraper Pro X

An advanced web scraping tool built with **Streamlit**, **Requests**, and **BeautifulSoup** that allows users to extract structured data from any website in a simple and interactive UI.

---

## 🚀 Features

- 🔗 Scrape any valid website URL
- 📌 Extract different types of data:
  - Headings (h1–h6)
  - Paragraphs
  - Links (absolute URLs)
  - Images
- 📊 Live preview of scraped data in table format
- 📁 Auto-save results as:
  - CSV file
  - JSON file
- 📥 One-click download (CSV / JSON)
- 🎨 Modern dark UI with custom styling
- ⚡ Fast and lightweight scraping using Requests + BeautifulSoup

---

## 🛠️ Tech Stack

- Python 🐍
- Streamlit
- Requests
- BeautifulSoup4
- Pandas
- JSON / OS utilities
